# Bridge contract used by this extension

Owned files: only `src/chrome-image-extension/**/*` and `tests/chrome-image-extension.test.cjs`. Parent owns all app backend/UI files.

All endpoints: POST JSON to `http://127.0.0.1:9223`; browser fetch injects `Origin: chrome-extension://<extension-id>`. No credentials/cookies. Fetch redirect is forbidden. `/pair` unauthenticated, subsequent requests `Authorization: Bearer <token>`. The server must pin the paired extension Origin and reject all other Origins, plus reject missing Origin. Extension 1.0.2 never exposes its token to the webpage/content script; token lives in `chrome.storage.local` with `setAccessLevel({accessLevel:'TRUSTED_CONTEXTS'})`, so it survives Chrome/tool restart. Selected tab, document ID and last connectivity error live only in restricted `chrome.storage.session`. Server persists capability encrypted on Windows. Pairing code is random 128-bit, single-use, has no time expiry, and allows at most eight guesses. It is invalidated on tool close, replacement code, or disconnect. Established capability is remembered until explicit disconnect; no command journal is cleared by disconnect.

- `/pair`: request `{code: string}`. response `{token: string}`; token expected 20–512 characters. Error JSON `{message: string}` and non-2xx.
- `/resume`: authenticated request `{tabId:number,documentId:string,path:string,ready:boolean,gate:null|'login'|'verification',draft:boolean,generating:boolean}`. JSON ACK, e.g. `{ok:true}`. Called only from the selected content tab's poll when its session document is missing or has changed. Extension first refuses any unfinished local command on previous tab (all unfinished commands after Chrome restart). Server must refuse while any active/unresolved dispatch exists; otherwise rebind exact tab/document and ACK. Extension stores new session document only after 2xx. No pairing code required.
- `/poll`: request `{tabId: number, documentId: string, path: string, ready: boolean, gate: null|'login'|'verification', draft: boolean, generating: boolean}`. response `{command: null | {id: string,kind:'generate',jobId:string,index:0..4,prompt:string,reference:{name:string,mimeType:'image/png'|'image/jpeg'|'image/webp',dataUrl:string},expectedConversationPath:null|'/c/<id>'}}`.
- `/event`: request `{tabId,documentId,path,commandId:string,type:'prepared'|'submitted'|'progress'|'complete'|'error',phase:string,message:string}`. response any JSON object, e.g. `{ok:true}`. Submitted phase is persisted by service worker **before** request, and the server must persist submitted before returning 2xx. Extension never clicks Send if the ACK request fails. `error.phase==='submitted'` means possibly sent, never resubmit. Progress phases are `awaiting-prompt`, `generating`, or `candidate`. Completion event comes after successful `/image` ACK.
- `/image`: request `{tabId,documentId,path,commandId:string,dataUrl:string}`; response any JSON object e.g. `{ok:true}`. Strict decoded bytes max 25 MiB. MIME PNG/JPEG/WebP; server must inspect magic/actual image and match command identity rather than trust MIME. Server should save exactly the command's index, emit preview progress and return success before next command.

The service worker pins tab explicitly selected in popup. `tabId` is replaced from Chrome's `sender.tab.id`, never accepted from content payload. `sender.frameId===0` and `sender.url` origin must be `https://chatgpt.com`. First poll calls `/resume` before pinning isolated script's random `documentId`. A safe reload with no unfinished command repeats `/resume` without any code. After Chrome restart no tab is auto-adopted: employee selects a ChatGPT tab then presses **Kết nối lại tab này** in popup; popup only stores selection, actual authenticated `/resume` must come from that real tab's content script. Reload/reconnect never replays a command. SPA transition `/` → `/c/<id>` is allowed only after locating the exact new user turn. A pending command on tab/doc mismatch must be marked uncertain by the server heartbeat/timeout; do not send again.

Marker appended by extension:

`SRM ${jobId} ảnh ${index + 1} lệnh ${id}`

Then `Mã lượt: ${marker}` and `Chỉ tạo đúng 1 ảnh, không trả lời bằng văn bản.` are appended to supplied prompt. Supply unmarked base prompt. Server must persist claimed **before** returning a command from poll. Extension additionally persists every claimed command ID in local storage before returning it to content, preventing duplicate submission across worker restart/reload.

`expectedConversationPath` should be null for image 1 on current selected tab, then the successfully locked `/c/<id>` for images 2–5. If there is already a conversation at image1, it is locked too. Completion requires exact appended prompt in one newly inserted user turn, exactly one following assistant turn, no new user turn, no generation/busy UI, a full-loaded IMG at least 500×500 with edit and download/share controls in its own generated-image card, no baseline source match, and stability ≥1.5 seconds. Original file source is fetched, never canvas exported or screenshot saved. Source URL must be HTTPS chatgpt.com/files.oaiusercontent.com or blob:https://chatgpt.com. Source/card/request/document are revalidated after fetch and before upload.
